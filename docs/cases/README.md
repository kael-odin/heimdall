# 真实授权案例

这个目录只放获得站点所有者授权、可以公开的 Heimdall 运行证据。它不是营销截图仓库，也不是“任意网站都能跑”的证明。

每个案例至少包含：

- 一份去掉登录态和内部路径的 `qa.json` 复现配置。
- 原始命令、运行时间、工具版本、页面和视口范围。
- `report.md`、`run.json`、`findings.json`、`qa-ci.json`，以及必要的截图。
- 一个 `manifest.json`，记录文件哈希和明确的未测范围。
- 结论只描述本次声明的页面、视口和检查点。

禁止放入：Cookie、Token、HAR 原文、后台账号、个人数据、未授权站点内容，以及无法公开的业务数据。
