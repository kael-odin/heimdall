## 3. 保真度（"更精细"的方向）

- [ ] **画布之外还有没有同类盲区**：canvas 已修（捕获阶段光栅化）。
      已排查过视频（正常，文件已本地化）与 iframe（外站嵌入，固有边界）。
      **已修**：`<base href>` 改基（Angular 类站点整页失去样式）、
      跨域样式表里的字体规则（图标连字名被当文字渲染）—— 两个都是换到 Angular
      才第一次踩到，见 HANDOFF §23.5。
      **WebGL 画布已修**（2026-10-12，moonshot.cn 首页）：读绘制缓冲区拿不到像素的
      （没开 `preserveDrawingBuffer`）改用元素截图兜底，并用 `countOpaquePng` 自证
      截到的不是空图。见 HANDOFF §33.2。
      尚未系统排查：CSS `@font-face` 可变字体轴、
      **闭包在 shadow DOM 里的样式**（现在只处理了 light DOM）
- [x] **交互镜像"离线也像直播"**（2026-10-13 关闭）。用户的原话是"我一直以为交互镜像
      即使离线，也能表现出直播的样子" —— 能做到，缺的是一整条本地化判据。
      实测：断网时 1.5 秒内像素变化 **0.00%**（联网 6.13%），WebGL hero 是一帧静止画面。
      现在：**0.00% → 7.63%**（比联网那次还高，本地没有网络延迟）；外域静态资源引用
      **39 → 0**，本地化 41 个文件 8.4MB。修了三处，每一处都是"不说就永远不知道"的那种：
      ① **判据把"站外"当成了"第三方"**（`!sameOrigin && !isImage → continue`）——
      moonshot 把整个应用的 JS、字体、WebGL 驱动放在 `statics.kimi.ai` 上，整套被跳过。
      改成看类型（脚本/样式/字体/图片/媒体/wasm）而不是看域名。
      ② **站外资源不能拍平成 `_ext/<sha1>.js`**：站外 JS 之间是**相对路径**互相引用的
      （Vite 清单里是 `./chunk-X.js` / `../chunks/chunk-Y.js`），拍平后 `../chunks/`
      解析到 `/lm/<host>/chunks/` → 404 → 模块链断掉。改成**保留原始目录结构**
      （`_ext/<host>/<原路径>`）。
      ③ **运行时拼出来的地址替换不到**：应用是"CDN 基址 + 相对路径"拼 chunk 地址的，
      文本里根本没有完整 URL。于是离线包把站外 CDN 的**整站前缀**接到 `_ext/<host>/`
      （只在离线包做；在线镜像的承诺是"未捕获的实时回源"）。
      **仍然成立的边界**（写清楚，不是缺陷）：跨域 **API 数据**离线无法伪造
      （HAR 回放只覆盖走 serve.mjs 的同源那部分）、第三方嵌入（YouTube/地图/统计）
      抓不回来。所以"离线像直播"覆盖**视觉与前端交互**，**数据是快照**。

- [ ] **克隆过程的"等待感"**（2026-10-13，用户提的）。实测：一次 40 秒的单页克隆，
      在 t=2.5/8/20 秒三次采样里，屏幕上能看到的文字**完全一致**（状态条"克隆中 · home"
      + 任务中心一行"home 运行中"），第 40 秒才跳成完成。根因：克隆有**六个具名阶段**
      和一条实时日志流，引擎都在推，但控制台只在**详情面板的「克隆」tab**里渲染它们 ——
      而那个面板要"选中该页 → 打开 → 切 tab"才看得到；`task.progress` 在 forge 这条路上
      **从来没被赋值过**（整站克隆/审计/导出都赋了）。所以不打开面板时，2-3 分钟里
      看到的是一句常量。待做：forge 补 progress（阶段名 + 序号）、浮层任务行加已跑时长、
      运行中的行加不定长动效、任务行显示"站/页"而不只是页名。

- [ ] **动效的可复刻度**：现在动效要么抓一帧、要么丢失。能否对常见类型
      （轮播、打字机、滚动触发）做"初始态 + 终态"双帧捕获？
      这会让 `dynamicShare` 那个缺口变小。
      **一个实测到的上限**：moonshot.cn 首页那条横向滚动的字标是 JS 驱动的
      WebGL 场景，两边都冻不住（`animation-duration:0s` 只管 CSS 动画）——
      抓到了、画对了，但永远停在不同相位，`dynamicShare` 0.78。
      所以这里的诚实读数是"静态部分没问题，剩余的都是动效相位"，
      而不是"复刻得差"

## 5. 产品

- [x] **首启向导**（2026-10-12，基础版）：星图空态里写清"侦察 → 克隆 → 拿走"三步 +
      登录提示。**仍缺**：已有站点时想从零再起一个没有引导（见 §4b）
- [ ] **多个交付包 = 站点群：单个很好部署，成"群"还差一个门户**（2026-10-13）。
      单个包是自包含的（零依赖 `serve.mjs` / `Dockerfile` / `docker-compose.yml`，
      `node serve.mjs --port 8080` 或 `docker compose up -d` 就完事），但它是**站点级**的：
      `heimdall-live.json` 里只有一个 `host`，`rewriteHtml` 只重写 `https://<host>/`，
      `root: mirror` 又直接占住 `/`。所以一台机器上想同时起 N 个站，要么一个站一个端口，
      要么按 Host 头分流（反向代理），**没有一个"总入口"**。
      要补的是一小层：① 一个门户页（列出所有站的 landing/镜像/报告入口）；
      ② 按 hostname 的分流配置（或者让一个 `serve.mjs` 认多 host —— 改动不大，
      路由本来就是 `/lm/<host>/...` 的形状）。属于"部署体验"，不影响单站产物。

## 读数口径（"报告说的话与产物是不是一回事"）

- [x] **控制台的「克隆槽」显示成 -1/2**（2026-10-12 关闭）。引擎用一串 if/else 归还槽位，
      末尾是兜底的 `else slots--`，于是**没占过槽的任务类型**（cas-gc / editmanifest /
      replace-domain）退出时也减一。难看只是表象：`used >= max` 那道闸门从此永不触发，
      **并发上限（默认 2 个 Chromium）静默失效**。现在槽位收进 `src/forge-slots.mjs`，
      归还一个没占过的槽会被拒绝并留痕，计数永远不会变负。
- [x] **任务失败时看不到原因**（2026-10-12 关闭）。任务历史里只有
      `Error: crawler/build_clone.mjs exited 1` —— 子进程的 stderr 只流去了引擎控制台，
      没有任何地方留存（事后翻 jobs.db 也只翻到同一句）。现在统一走
      `src/child-run.mjs`：stderr 既实时转发、又留一份尾巴并进错误信息。
      当天就用上了：它把一句 `exited 1` 变成了具体的 `ReferenceError: …`。
- [x] **同一个页面两个分数（SEO 审计）**（2026-10-13 关闭）。进度流给 `evaluatePage`
      多传了 `noindexIntent: true`，报告那遍没有 → noindex 页在进度里高最多 12 分，
      而 CI 基线取的是报告那个更严的数。两处共用一份 `pageCtx`，并加了守卫。
- [x] **三个"把没测到报成测得差"**（2026-10-13 关闭）：回收的自检 fail-open

- [x] **两处报告的覆盖面没说清**（2026-10-13 关闭）：资产缺口扫描默认只扫前 60 页，

## 判断依据

排优先级时问三个问题：

1. **它挡住真实使用吗？**（规模 → 挡）
2. **它会让结论变得不可信吗？**（保真度盲区 → 会；报告口径错 → 会）
3. **演示时讲得清价值吗？**（审计深度 → 讲得清；i18n → 讲不清）

三个都是否的，不做。
