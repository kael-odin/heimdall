## 2. 审计深度（对标一流 SEO 工具的部分）

已有 66 条规则 / 六分类，且能识别 JS 渲染依赖与 hreflang 问题。缺的是：

- [x] **分页 / 分面导航**（2026-10-11）：6 条规则 + 抓取排序。连带发现一个真问题 ——
      分页链接通常排在页尾，按 DOM 顺序入队会被页数配额挤掉，于是"最该看的页面最先被丢"
- [x] **结构化数据深度校验**（2026-10-11）：5 条规则，按 Google 富结果文档核必填字段
      （Product 要 name + image + offers|review|aggregateRating）、日期格式、图片绝对地址
- [x] **历史趋势**（2026-10-11）：`workspace/<host>/history.json` + 报告页走势图，审计与整站克隆各记一笔
- [~] **真实用户指标（CrUX）**：做成**可选接入** —— 需自备 `HEIMDALL_PSI_KEY`。
      无 Key 的匿名配额是全局共享的（实测直接 429），所以默认不取，报告里如实写
      "只有实验室数据"。解析逻辑已单测；取数那一步没有 Key，无法在这里验证
- [ ] 分面导航的**组合爆炸**目前只报"有多少个参数页"，没有按组合数估算抓取预算影响

**规则数由测试钉住**：`core/test/seo-rule-count.test.mjs` 从源码数规则并断言总数。
这个数字在文档里写错过两次（"40+" → "56"，按源码数只有 54），不再靠人记。

**明确不做**：外链分析、关键词研究、排名追踪 —— 那是数据生意，需要买数据源。
我们的定位是"站内技术审计 + 可核验的复刻"，不宣称对标 Semrush。

## 3. 保真度（"更精细"的方向）

- [ ] **画布之外还有没有同类盲区**：canvas 已修（捕获阶段光栅化）。
      已排查过视频（正常，文件已本地化）与 iframe（外站嵌入，固有边界）。
      **已修**：`<base href>` 改基（Angular 类站点整页失去样式）、
      跨域样式表里的字体规则（图标连字名被当文字渲染）—— 两个都是换到 Angular
      才第一次踩到，见 HANDOFF §23.5。
      尚未系统排查：WebGL 画布（`toDataURL` 需要 `preserveDrawingBuffer`）、
      CSS `@font-face` 可变字体轴、`<video>` 的 poster、
      **闭包在 shadow DOM 里的样式**（现在只处理了 light DOM）
- [ ] **动效的可复刻度**：现在动效要么抓一帧、要么丢失。能否对常见类型
      （轮播、打字机、滚动触发）做"初始态 + 终态"双帧捕获？
      这会让 `dynamicShare` 那个缺口变小

---

- [x] **交互镜像的路径前缀边界**（2026-10-11 关闭）：`/lm/<host>/<path>` 会被纯 CSR
      站的路由当成真实路径，crawlee.dev / ant.design / vitest.dev 因此落到它们自己的 404。
      已按本来的设想加**独立域名入口** `<host>.localhost:8900`（pathname 就是站点自己的路径），
      两个入口并存、服务同一份产物：控制台上「交互镜像」走独立域名，「/lm 备用」走前缀。
      当初担心的 `*.localhost` 解析问题**实测不成立** —— 这台机器上 fake-IP 代理会把
      `vitest.dev.localhost:8900` 转回 127.0.0.1 且 Host 原样保留。仍需注意：无代理且
      系统不认 `*.localhost` 的环境（少数旧浏览器）用前缀入口

## 判断依据

排优先级时问三个问题：

1. **它挡住真实使用吗？**（规模 → 挡）
2. **它会让结论变得不可信吗？**（保真度盲区 → 会；报告口径错 → 会）
3. **演示时讲得清价值吗？**（审计深度 → 讲得清；i18n → 讲不清）

三个都是否的，不做。
