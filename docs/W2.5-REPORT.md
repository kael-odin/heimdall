# W2.5 验收报告 · 引擎接线 + 星图生长

日期：2026-09-30 · 状态：**✅ 通过**

## 结果

端到端打通：控制台输入 `thordata.com` → 引擎实时侦察 → SSE 事件流 → 星图逐星点亮生长 → 完成 32 pages / 282 edges（清洗后 200）。HUD 实时跳动，"光点出发 → 新星点亮 → 星图定稿"状态机走通。

- **recon.mjs 事件化**：每页入图 emit `kind:'page'`、链接发现 emit `kind:'edges'`（两端点亮后连线浮现），人类日志转 stderr，stdout 只走 `@@EVENT@@` 行协议。
- **engine-server.mjs**（:8900）：单任务队列 + SSE（晚连接全量重放）+ atlas 产物服务 + CORS。
- **origin 校准**：thordata.com 301 → www.thordata.com，链接过滤用输入 origin 导致全灭——先探测落地 origin 再开爬，目录名统一去 www。
- **Atlas.vue live 模式**：黄金角增量布局（节点增加不重排）、出生动画（奇点飞入 + easeOutBack 缩放 + 辉光爆发）、pendingEdges 两端点亮后转正淡入。

## 踩坑（四连，都是"实时流前端"的经典坑）

1. **vite proxy 缓冲实时 SSE**：重放（一次性 write + end）能收，分批实时事件收不到 → 前端直连引擎端口，CORS 放开。
2. **CORS 头漏加**：`json()` 帮助函数没带 `Access-Control-Allow-Origin`，preflight 过了但 POST 响应被浏览器拦（node fetch 测不出来，必须浏览器测）。
3. **事件判别字段撞名**：`emit({type:'page', ...node})` 展开后 `type` 被 node.type（marketing）覆盖，page 事件全没识别 → 事件统一用 `kind`，节点属性保留 `type`。
4. **Vue computed 缓存吞掉非响应式数组**：`nodes.push()` 后 HUD 恒 0（computed 依赖没变不重算，`nodes.length` 根本不在依赖里）→ HUD 改 ref，在渲染循环里"值变才写"同步。

调试教训：node fetch 模拟全流程（事件全通）+ playwright 抓 console/network 二分定位——引擎侧与浏览器侧问题各占一半，别猜，两端各验一次。
