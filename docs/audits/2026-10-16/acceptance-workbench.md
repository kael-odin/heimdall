## 控制台：真实浏览器操作受控夹具

执行 `pnpm acceptance:smoke`，真实 Chromium 访问构建后的控制台，通过表单创建任务，执行 2 路由 × 3 视口及一个菜单组合断言，共 **39 项检查**：36 通过、3 个行为断言失败，可靠测量覆盖 **39 / 39**，最终门禁为 **failed**。

该例的视觉分约 **99.9%**，但菜单点击后的 `aria-expanded` 在手机、平板、桌面均错误，三个断言全部阻断，证明功能失败不会被视觉高分掩盖。这里的 3 是同一个行为缺陷的三个视口结果，不是三个独立缺陷样本。

桌面 1440×1000、手机 390×844 通过页面身份、非空页面、无框架错误层、console 健康、鉴权证据图片、下载、刷新恢复及无横向溢出检查。还实测了无 Token 返回 401、无效输入 400、同引擎重复创建 409、重启把未完成任务恢复为 interrupted、未知证据及路径越界被拒绝。手机通过“查看结果”到报告区。

控制台 AI 链路使用本地模型模拟器：运行验收时零次模型请求，点击后才调用；模型尝试新增检查或将门禁改为 passed 都被丢弃，刷新后恢复独立建议，原报告仍为 failed。此项证明端到端接线与边界，不证明外部模型质量。

浏览器结果、报告与截图位于 `core/workspace/_runs/acceptance-console/`；精简归档见本目录下 `evidence/acceptance-workbench/console/`。该烟测会把任务证据从临时数据目录复制到 `run-evidence/` 后再清理临时服务，原始证据可继续复核。

## 真实模型解读

在受控菜单报告上，另行调用本机已有 `deepseek-flash` 配置，返回 `completed` 与 3 条合法建议。模型把三条结果识别为同一个行为断言的多视口失败，指出只应复核 `aria-expanded` 状态，并保留原始结论。请求仅含脱敏检查摘要，没有上传截图、原始会话或凭据。此验证是一次真实模型调用；模型建议本身仍是候选，不视为浏览器或业务真值。

结果保存在 `core/workspace/_runs/acceptance-console/ai-triage-configured-model.json`，精简归档到 `evidence/acceptance-workbench/console/ai-triage-configured-model.json`。

## 本轮发现并修正的验收器缺陷

- 原有多视口验证的最终状态未纳入功能结果；新增独立验收门禁中，任何明确行为失败都能阻断。原有历史报告没有被重算或伪装成新口径。
- 恢复为 interrupted 的旧任务可能被旧 worker 改回 completed；存储层禁止覆盖终态，旧进度和旧完成写入被拒绝。
- 整页遮罩会让不同页面出现视觉满分；记录遮罩并集和有效区域，覆盖超过 80% 时视觉与结构待复核。
- 原始首屏截图会漏掉下方内容；改为预算内全页截图，超高或超像素退为首屏并待复核。专门反例已验证底部缺失 700px 被检出。
- 双方截图失败、证据文件丢失或不完整覆盖不能通过。
- 新数据根未有 workspace 时，站点列表返回 500 并遮住导航；修正为空列表，使独立验收可从全新环境开始。
- 演示 `.mjs` 被 Node 测试自动发现时会常驻等待；现在只有显式指定端口才启动服务器，导入和测试发现保持无副作用。

## 质量门与剩余边界

完整 core 回归：**926 项，924 通过，0 失败，2 项 Docker 环境测试按既有条件跳过**。新增证据完整性补充用例另行定向通过；最终精确统计与命令输出归档到证据目录。语法检查、控制台构建、原有端到端 smoke、项目验收 smoke 和固定真值基准均通过；文档链接与推送后的 CI 状态在提交前后复核。

并发执行整套浏览器回归期间，另一次控制台复验曾只达到 33 / 39 可靠判定，烟测按预期失败。该次未保留足够的单项详情，不能声称已确认根因或消除资源压力下的波动；后续单独运行已恢复 39 / 39。烟测现已改为无论成功失败均先保留完整任务证据，再清理临时服务。默认单项超时与短观察窗口仍可能把慢环境标记为受阻，不能据此推断目标业务失败。
