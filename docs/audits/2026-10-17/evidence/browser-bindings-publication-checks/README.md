# Browser 来源绑定：独立发布检查

本目录记录本机证据包完成后的独立发布检查。它与已冻结的 browser-bindings 包分开，避免在完成凭据之后继续修改该包。

`independent-verification.json` 记录完整文件集合、247 项清单、217 份来源副本或 gzip 回环，以及 13 个 tar 中的 440 份原件逐字节核对；同时扫描本机包、上一片精确 CI 归档与解压材料的四类强凭据格式。该格式扫描有明确边界，不能证明检测了任意秘密。

`staged-verification.json` 记录两个已冻结包进入 Git 暂存区后的逐字节核对，包含被根 ignore 规则排除的 CI 原始日志。文档链接命令、stdout、stderr 和退出记录单独保留。专项、完整 Core、CI、Docker 和发布核验没有合并计数。

首次暂存空白检查发现 GitHub 原始日志中的真实尾空格。没有修剪冻结日志，也没有改变它们的 SHA；证据父目录的属性仅对本批 CI 渲染日志、命令原 stdout 和解压日志关闭空白风格检查。产品源码、报告和其余文件仍执行检查，随后独立运行全暂存检查并确认退出码。
