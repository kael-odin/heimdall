# Xspark 真实复测：先修现有规则，不增加通用检测器

2026-11-12，在 Xspark 所有者授权范围内，使用 Heimdall 对官网、正式/测试仪表板和正式/测试后台做了新一轮真实 Chromium 复测。本文只收录脱敏聚合结论；登录态、截图、页面正文、接口正文和原始运行文件留在 Xspark 本机试点目录，不进入 Heimdall 仓库。

## 大白话结论

这次确实访问到了五个入口，登录探活成功，写操作按策略阻断。官网和两套仪表板在建立本轮新基线后没有稳定可提单的视觉回归；两套后台在两个视口重复出现同一类真实问题：筛选控件在 Chromium 无障碍树里没有可用名称。现有 `a11y-form-label` / `a11y-lang` 检测器已经能抓到它，不是缺一个新通用检测器。

结论：**暂不增加通用检测器，先修 Xspark 页面、补齐受限出口和业务检查证据，再复测。**
