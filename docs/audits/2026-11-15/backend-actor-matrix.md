# B3 认证与权限矩阵标签实测

日期：2026-11-15。范围：B3 生成脚手架中的受控本地授权夹具；没有使用生产账号、真实 Cookie 或真实令牌。

## 实际流程

在现有 `agent-backend-scaffold.test.mjs` 夹具里声明四条已人工确认的只读规则：

1. `actor=anonymous`：无认证头，请求 `/api/private` 预期 `401`；
2. `actor=owner`：从环境变量注入授权头，预期 `200` 和允许标记；
3. `actor=guest`：从环境变量注入另一身份，预期 `403` 和拒绝标记；
4. `actor=invalid-token`：从环境变量注入无效凭据，预期 `401`。

认证值只在检查进程内存中使用。`backend-check.json` 记录身份标签和规则状态，不记录环境变量名对应的值、请求体或响应正文；`site-assessment` 从同一份脱敏报告汇总每个身份的 `total`、`passed`、`failed`、`incomplete` 和整体 `status`。

## 结果

| 身份 | 预期 | 结果 |
| --- | --- | --- |
| `anonymous` | 401 | passed |
| `owner` | 200 | passed |
| `guest` | 403 | passed |
| `invalid-token` | 401 | passed |

定向 B3 测试 6/6 通过，认证值和测试正文泄露断言通过；站点评估测试 23/23 通过，语法检查 774 个文件通过。

## 边界

该案例证明了 Heimdall 能把经过授权的身份矩阵接入现有业务规则检查，并把结果安全地投影到 AI 任务摘要。它不能证明任意生产站点的登录流程、令牌刷新、资源归属、角色继承、并发竞态、写入权限或完整后端等价；这些仍需对应站点的独立测试账号和明确授权。
