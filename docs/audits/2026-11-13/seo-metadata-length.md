# 标题与描述长度实测

2026-11-13，修正固定字符数导致的 SEO/GEO 评分偏差。复用原规则、GEO、报告和三个测试文件，没有新增运行模块、依赖或测试文件；64 条 SEO 规则及采集字段不变。

## 依据与改动

Google Search Central 的[标题指南](https://developers.google.com/search/docs/appearance/title-link?hl=en)和[摘要指南](https://developers.google.com/search/docs/appearance/snippet?hl=en)说明标题与 meta description 没有固定长度上限，展示按设备宽度截断；文案应准确、清晰。工具原有的 10/60/50/160 字符边界不能据此证明内容有缺陷或质量合格。

- 保留四个长度规则 ID 和原提示线，严重度统一为 `info`，不再扣分；建议按语言、用途和实际展示人工检查。缺少 title 或 description 仍按原严重度提示，缺失描述的建议移除固定长度要求。
- GEO 的 `geo-citation-description` 只核对 description 是否为非空文本，标题改为“页面摘要有值”；无值仍失败，不以 50 字符证明概括质量或实际引用。
- HTML 报告按评分版本说明该边界，不给旧报告补写新口径。SEO 评分 **13**、测量 **8**、GEO 方法 **8**；旧评分 12 基线保留，须选新路径重新建立并审核。现有基线、矩阵和站点评估继续隔离不同或未知口径。

## 真实样本

匿名公开 GET 冻结豆瓣首页、RFC 9309、Google 标题指南、Example Domain，另保存官方摘要指南。只保留 HTML、状态和指定的非凭据响应头；未保存 Cookie。Chromium 重放原始 HTML 和这些头，其他请求全部阻断，不把该运行作为线上性能测量。

初始 HTML 与渲染后的标题、描述在空白规整后逐项一致；Google 标题的原始采集保留非断行空格，故报告长度按渲染侧的 108 个代码单元记录。前后评分使用同一份采集 JSON，其他问题字段保持一致，仅缺失描述的建议文案按上述改动更新。
