# hreflang：完整地址与 Google 标记形式

2026-11-13。用新采集的公开 HTML、同批冻结重放及受控元数据反例，修正国际化 SEO 规则，不把工具分数变化解释为搜索效果变化。

## 纠正的三项判断

- 自指匹配此前丢弃查询、协议、端口、`www` 和尾斜杠差异，还可能让空地址相互匹配。现在保留完整 HTTP(S) 地址，只应用 URL 标准的主机大小写、默认端口等规范化并去掉片段；访问地址与声明 canonical 可精确匹配，不据相似字符串推断其他 URL 等价。
- `x-default` 是按语言回退需求配置的建议，不是每个多语言页面的必填项。保留原规则 ID，严重度改为 `info`，不扣分。
- 语言检查明确限定为 Google 支持的标记形式：两字母语言、可选脚本、可选两字母地区或 `x-default`。不再把三字母语言和 `es-419` 等一般 BCP 47 形式自动当作 Google 支持，也不将其误称为通用语言标记非法。本检查不核对 ISO 代码表成员。

机制依据为本次取得 HTTP 200 的 [Google 本地化版本指南](https://developers.google.com/search/docs/specialty/international/localized-versions?hl=en)。官方初始 HTML 与摘录保存在外部证据中；语言形式判断不替代完整代码表、目标抓取或跨页双向检查。
